Login & Authentication

📱
SCREENSHOT: Login Screen
The ITforP Core login screen with company branding
  • Branded Login Screen — Displays the ITforP logo on a full-screen company-branded background. If the logo fails to load (e.g., after a session reset), a styled text fallback automatically renders "ITforP CORE" so the screen always looks polished.
  • Secure Email & Password Login — Authenticated via Supabase Auth with encrypted credential storage.
  • Password Reset — Tapping "Reset Password" navigates to a dedicated screen that sends a reset link to the user's registered email.

Section 02

Jobs List

📱
SCREENSHOT: Jobs List — Admin
All jobs across all technicians, grouped by status
📱
SCREENSHOT: Jobs List — Technician
Technician view showing only their assigned jobs

Role-Based Visibility

  • Admins see every job in the system across all technicians.
  • Technicians see only the jobs assigned to them — nothing more.

Status Sections

Jobs are automatically sorted and grouped into labeled sections:

SectionDescription
ActiveJobs currently being worked on by a technician
Pending ApprovalWork completed by the tech, awaiting admin sign-off
ScheduledUpcoming jobs not yet started
CompletedFully finished and admin-approved jobs
ClosedArchived jobs — fully resolved

Job Cards

Each card shows the job number, client name, site address, current status (color-coded), assigned technician, scheduled date, star rating (if reviewed), and payment status indicators (admin only).

Real-Time & Auto-Refresh

  • Pull-to-Refresh — Swipe down at any time to manually reload.
  • Real-Time Updates — The list automatically updates when any job changes using Supabase real-time subscriptions, with a 15-second polling fallback to ensure accuracy even in poor network conditions.
  • Auto-Refresh on Focus — The list silently refreshes whenever the user returns to it from a job detail screen.

Job Header

  • Displays job number, client name, and full site address. The address is tappable to open Apple Maps / Google Maps for turn-by-turn navigation.
  • Collapsible Description Card — The job description section can be tapped to expand or collapse, keeping the view clean when it isn't needed.
  • Admin-only: Edit Job and Export Work Order PDF buttons appear at the top of the screen.

Trip Cards

A job can have multiple trips (site visits). Each trip card displays the trip number, scheduled date/time, assigned technician, current status badge, and GPS check-in info. Two sections inside each card are independently collapsible:

  • Scope of Work — Tap the header to expand the full scope text, or collapse it to save space. Each trip's scope can be toggled independently.

Trip Status Workflow

The technician advances the trip through statuses using a single action button on each trip card:

StatusButton LabelWho Can Advance
ScheduledGo En RouteTechnician
En RouteCheck InTechnician
Checked InCheck OutTechnician
Checked OutSubmit for ApprovalTechnician
Pending ApprovalApprove / CompleteAdmin
Completed——

GPS Check-In Verification

When a technician taps Check In, the app reads their current GPS location and compares it to the job site address. If they are more than 500 meters away, they receive a warning and are asked to confirm they are physically on-site before the check-in is recorded.

Future Date Block & Reschedule Request

If a trip is scheduled for a future date, technicians cannot tap Go En Route. They must send a reschedule request to the admin, who can then move the trip to today with a single tap.

  • The technician sees a message explaining the trip date and a Send Request button.
  • The request (with reason) is saved to the trip record in the database and logged in the event history.
  • The admin sees an orange banner on the trip card: "Reschedule Request from [technician]."
  • The admin can tap the banner to approve and reschedule the trip to today at 9:00 AM, or dismiss the request.
  • On approval, the technician receives a push notification and the action is logged in the event history.

Digital Signature Capture

When submitting a trip for approval, the technician can capture a digital signature from the client directly on-screen using a finger or stylus. The signature is stored with the job record.

Technician Star Rating

After a trip is completed, admins can leave a star rating (1–5 stars) and a written review for the technician. Ratings appear on job cards and the technician's profile.

Admin Trip Management

  • Add new trips with a date, scope of work, and technician assignment
  • Edit existing trip details (date, scope of work)
  • Delete trips
  • Assign or reassign a technician to any trip
  • Remove a technician from a trip

Export Work Order PDF

Admins can generate and share a professional PDF work order for any job with a single tap. The PDF is formatted for client or record-keeping use.

Section 05

Job Detail — Attachments Tab

📱
SCREENSHOT: Attachments — Grid View
Photo grid with uploaded site images
📱
SCREENSHOT: Attachments — FAB Menu
Floating action button expanded: Camera, Library, Document
  • Trip-Based Organization — Attachments are organized per trip. A selector chip at the top switches between trips.
  • Photo Grid — Uploaded images display in a responsive grid. Tap any image to view it full-screen.
  • Document List — Non-image files (PDFs, Word docs, etc.) are listed with filename and file size.

    • Photo Library — Browse and select existing photos
    • Document / File — Pick any file type from device storage

  • Delete Attachments — Long-press any attachment to delete it (with a confirmation prompt).

Create Job Fields

  • Job Number — Unique identifier for the job

Notifications

📱
SCREENSHOT: Notifications Screen
Notification inbox with unread count banner and individual entries
  • In-App Inbox — All notifications are stored in a scrollable inbox accessible from the navigation bar bell icon.
  • Unread Indicators — Unread items appear in bold. A banner at the top shows the total unread count with a one-tap Mark All Read shortcut.
  • Tap to Navigate — Tapping any notification opens the relevant job directly.
  • Delete — Individual notifications can be deleted from the inbox.

Push Notification Events

The following events trigger push notifications to relevant users:

Job status changes Check-in / check-out Submitted for approval Job approved New notes added Reschedule request sent Reschedule approved

Smart Filtering: Users never receive push notifications for their own actions. Admins are not notified when they personally update a job. Chat messages do not trigger push notifications.

Key Workflows

13.1 — Full Job Lifecycle (Technician View)

End-to-End Trip Execution

1
Job assigned by admin — technician receives push notification
↓
2
Technician opens job in Jobs List → reviews scope in Instructions tab
↓
3
Day of job: taps Go En Route (blocked if future date — see 13.2)
↓
4
Arrives on site: taps Check In — GPS location is verified against site address
↓
5
Completes work — uploads photos, adds notes, communicates via Chat
↓
6
Taps Check Out — optionally captures client digital signature
↓
7
Taps Submit for Approval — admin receives push notification
↓
8
Admin reviews job, attachments & notes → taps Approve / Complete
↓
9
Job moves to Completed — technician notified

13.2 — Reschedule Request Workflow

Future-Date Trip Reschedule

1
Technician taps Go En Route on a future-dated trip — app blocks the action
↓
2
App shows scheduled date and offers a Send Request button
↓
3
Technician enters a reason and submits — request saved to the trip & event history logged
↓
4
Admin receives push notification
↓
5
Admin opens job → sees orange banner on the trip card
↓
6
Admin taps banner → chooses Reschedule to Today (sets time to 9:00 AM)
↓
7
Technician receives push notification — trip is now ready to start
↓
8
Action logged in Event History with timestamp and user attribution

13.3 — Multi-Trip Jobs

A single job can have multiple trips (site visits) — useful for follow-up visits, phased projects, or warranty returns. Each trip has its own:

Scope of work Scheduled date & time Assigned technician Attachments Notes Status progression

Admins can add additional trips from the Overview tab at any time. All detail tabs (Instructions, Attachments, Notes) include a trip selector to switch context.

13.4 — Event History & Audit Trail

Every significant action is automatically logged:

Status changes Check-in & check-out Submission & approval Reschedule requests Reschedule approvals Technician assignments Notes added Attachments uploaded

Each event records the timestamp and the user who performed the action, creating a complete and tamper-evident audit trail for every job.
